Arduino Project

Neopixel • Arduino • Programming

The Project

For this project, I created a neopixel lighting system using Arduino. The system features three different lighting modes that can be switched between.

Project Goal:

Create a mood lighting outcome using NeoPixels and a push button. The user can cycle through lighting modes such as:

  • Calm (pulsing blue)
  • Focus (warm white)
  • Party (rainbow swirl)
  • LCD screen stating the current mode and telling you how to change the mode

This project taught me how to create projects hands on with eletronics and programming.


Testing button:

I made sure each mode worked by refining it several times and testing it by pressing the button at various speeds.


How I knew each mode worked:

Having tested in tinker cad, where wiring is not required to be as specific like in real life, I made sure each light mode worked properly with the correct wiring and code in which it does.


How many times I refined and updated code:

Several times to fix bugs and make sure things looked correct. I also updated my code several times to try and fix the LCD screen problem however nothing worked.


The main problem with the arduino is that the neo pixel is very delicate therefore when you move around the neo pixel the light flickers lots.

I made sure the button logic was working by pressing it at various speeds during different phases of the animation.

If the project didn't work as expected, I tried to see if was just the neo pixel flickering, but if it wasn’t I bug checked the function of the animation seeing if anything is incorrect.

Commenting on each individual function helped organization, as well as making each function do its own animation.

I checked the animations on both tinker cad and Arduino making sure the brightness and color was correct. If it wasn’t I would adjust it.

I tried adding a LCD screen to say the mode and how to change the animation. When I added the lcd screen it worked on tinker cad but not Arduino, eventually I scrapped it but moved some components from that to the main project as additional things.
